## Start with the workflow you need

VisualGuard compares browser screenshots and DOM evidence between two environments, against saved baselines, or inside existing Playwright tests. Deterministic analysis works without AI. Gemini or Ollama can add explanations and repair proposals.

Browser capture runs on your computer or CI worker. A shared dashboard adds persistent history, project access, team reviews and approved baselines. Dashboard-triggered tests use your connected private runner.

## Small setup. Clear next steps.

Install the package in the application you want to test. Start with one route and one viewport. Inspect the report before changing tolerances or adding optional services.

The website is being implemented on a feature branch. Published-versus-source applicability appears on each guide; see release notes before upgrading an existing workspace.
