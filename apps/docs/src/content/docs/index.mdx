## What VisualGuard does

VisualGuard opens your pages in a real browser and takes screenshots. It compares them with a reference and tells you what changed. The reference can be another running version of your site, saved screenshots, or an earlier step in a Playwright test.

- **No AI needed.** The built-in analysis finds changed pixels and links them to the page elements that changed. Gemini or Ollama can add plain-language explanations and repair suggestions if you want them.
- **No account or database needed** for local tests. Results are saved as files with an HTML report.
- **An optional dashboard** adds run history, projects, team reviews and approved baselines. It can run on your computer with a built-in SQLite file, or on a shared host.

Start with one page and one screen size. Read the report before you change tolerances or add optional services.

:::note[Release availability]
Install the current npm release and keep its resolved version in your lockfile. Dashboard test execution depends on the installed package, host settings and browser availability. If your dashboard does not offer host capture, connect a private runner or upgrade. See [release availability](/releases/).
:::
